# Getting help

1. Read [docs/help.md](docs/help.md) for common problems and fixes.
2. Check [docs/permissions.md](docs/permissions.md) if a screen asks for a permission.
3. Search the [issues](https://github.com/Ol775/nephele/issues), then open a new one if yours isn't there. Include your macOS and Nephele versions and what you did. **Never paste an API token.**
4. Security problems: use the private route in [SECURITY.md](SECURITY.md).

Nephele is a small, independent, volunteer project. There is no guaranteed response time.
